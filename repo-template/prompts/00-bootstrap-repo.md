# Bootstrap do repositório

Use `$bootstrap-dotnet-repo` neste repositório.

- Não altere código de produção, dependências, banco ou CI.
- Execute primeiro a inspeção determinística da skill e confirme fatos em projetos, scripts, CI, README e testes.
- Atualize apenas memória técnica confirmada: `AGENTS.md` e `docs/ai`.
- Não use fan-out amplo; acione `repo_explorer` somente para uma lacuna delimitada.
- Informe fatos confirmados, fontes, lacunas e perfis recomendados.
- Ao terminar, solicite uma nova tarefa para carregar as instruções atualizadas.
